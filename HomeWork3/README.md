# AI Image Chat — Домашняя работа 3

Приложение на C# / WinForms, которое принимает команды на **естественном языке** (русском или английском), интерпретирует их через локальную языковую модель (**LM Studio**) и применяет соответствующую обработку к изображению с помощью **OpenCV**.

---

## Как работает нейросеть

```
Пользователь пишет текст
        ↓
LM Studio (локальная LLM у студента) получает запрос через OpenAI-совместимый API
        ↓
Модель возвращает JSON с командой, например:
    {"type":"rotate","angle":90,"reply":"Поворачиваю на 90°."}
        ↓
Приложение разбирает JSON и вызывает нужную функцию OpenCV
        ↓
Результат отображается в окне
```

**Нейросеть не обрабатывает изображение сама** — она только переводит естественный язык в структурированную команду. Всю обработку выполняет OpenCV.

> В модель передаётся **только текст** запроса и размеры изображения (`Image size: WxH. Command: ...`) — сами пиксели не отправляются. Поэтому подойдёт любая инструктивная LLM, умеющая выдавать чистый JSON; vision-возможности моделей не используются.

## 5 основных команд (панель быстрых кнопок)

| Кнопка / фраза | Действие | Функция OpenCV |
|----------------|----------|----------------|
| **↔ Перевернуть** / «отразить зеркально» | Зеркальное отражение (горизонталь / вертикаль / оба) | `Cv2.Flip` |
| **📐 Изменить размер** / «уменьшить до 800 пикселей» | Изменение разрешения с сохранением пропорций | `Cv2.Resize` |
| **🎯 Объекты** / «найти красные объекты», «выделить контуры» | Поиск контуров или подсветка цветных областей (red / green / blue / skin) | `Cv2.FindContours`, `Cv2.InRange` |
| **⬛ Сделать ч/б** / «сделать чёрно-белым» | Перевод в оттенки серого | `Cv2.CvtColor` |
| **✏ Края** / «обнаружить края» | Выделение контуров алгоритмом Кэнни | `Cv2.Canny` |

## Полный список команд

Все команды доступны текстом или через меню **«📋 Команды»**. Внутреннее имя — это значение поля `type` в JSON, которое возвращает модель.

| `type` | Что делает | Реализация OpenCV |
|--------|-----------|-------------------|
| `rotate` | Поворот на произвольный угол (холст расширяется, чтобы не обрезать углы) | `GetRotationMatrix2D` + `WarpAffine` |
| `flip` | Зеркальное отражение | `Cv2.Flip` |
| `resize` | Изменение размера с сохранением пропорций | `Cv2.Resize` |
| `extract_channel` | Извлечение канала: red / green / blue / hue / saturation / value | `Cv2.Split`, `Cv2.CvtColor` |
| `detect_objects` | Контуры или подсветка цветных областей (red / green / blue / skin) | `Cv2.FindContours`, `Cv2.InRange` |
| `thermal` | Эффект тепловизора (инфракрасная карта цветов) | `Cv2.ApplyColorMap` (Inferno) |
| `grayscale` | Перевод в оттенки серого | `Cv2.CvtColor` |
| `blur` | Размытие, сила 1–20 | `Cv2.GaussianBlur` |
| `style_transfer` | Стилизация: anime / cartoon / disney / sketch / oil_painting / watercolor | билатеральные фильтры, адаптивный порог, HSV |
| `adjust` | Регулировка яркости и контраста | `Mat.ConvertTo` |
| `edge_detection` | Обнаружение краёв | `Cv2.Canny` |
| `remove_region` | Удаление области с «умным» закрашиванием (inpainting) | `Cv2.Inpaint` (Telea) |

> Стили — это **классические приёмы OpenCV, а не отдельная нейросеть**: например, «мультяшность» получается несколькими проходами билатерального фильтра плюс чёрные контуры через адаптивный порог.

## Возможности интерфейса

- **Чат** с историей сообщений (вы / AI) и дружелюбными ответами модели.
- **Быстрые кнопки** для 5 основных операций и меню **«📋 Команды»** со всеми возможностями.
- **Открыть / Сохранить** изображение (jpg, png, bmp, tiff, webp).
- **↩ Отменить** (Undo) — полная история состояний через стек.
- **🔍 Во весь экран** — просмотр в отдельном окне.
- **⚙ Настройки** — смена URL сервера и модели «на лету».
